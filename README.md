📊 Netflix Movies and TV Shows Dashboard
This project presents a Power BI dashboard built using a dataset of Netflix titles, showcasing trends and insights about content available on the platform.

🔍 Overview
Analyzed the Netflix Titles dataset (netflix_titles.csv) to explore trends across genres, countries, release years, and more.

Developed an interactive dashboard using Power BI to visualize and interpret the data.

The project includes KPIs, trend analysis, and visual storytelling to present data-driven insights.

🛠️ Tools & Technologies
Power BI (.pbix file)

Excel/Power Query

Python (optional preprocessing)

Netflix dataset (netflix_titles.csv)

📌 Key Features
Total number of Movies and TV Shows

Distribution by country and year

Genre popularity

Content ratings breakdown

Interactive filters and slicers for deep analysis
